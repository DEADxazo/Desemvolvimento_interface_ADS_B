## 👨‍💻 Sobre

Este repositório reúne atividades práticas, exercícios, experimentos e projetos desenvolvidos durante a disciplina **Desenvolvimento de Interfaces**, no curso de **Análise e Desenvolvimento de Sistemas (ADS)**.

O objetivo é registrar a evolução dos estudos, aplicar conceitos de desenvolvimento web e construir uma base prática em criação de interfaces e páginas web.

---

## 📂 Organização

```text
Desenvolvimento_interface_ADS_B/
├── JavaScript/
│   └── Exercícios e práticas de JavaScript
├── ProjetoWeb/
│   └── Materiais e atividades do projeto web
├── LICENÇA
└── README.md
```

> A estrutura será ampliada conforme novas atividades e projetos forem desenvolvidos.

## 📌 Padrão de organização

Sempre que possível, cada atividade será armazenada em uma pasta própria, contendo os arquivos necessários para execução e documentação.

```text
nome-da-atividade/
├── index.html
├── style.css        # quando separado
├── script.js        # quando necessário
└── README.md        # documentação, quando aplicável
```

---

## 🚀 Como visualizar os projetos

1. Clone ou baixe este repositório.
2. Abra a pasta do projeto desejado no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador (ou utilize a extensão Live Server, se disponível).
4. Para projetos JavaScript, siga as instruções específicas incluídas na atividade.

```bash
git clone https://github.com/DEADxazo/Desenvolvimento_interface_ADS_B.git
```
