# JavaScript — Aula 02 | ADS

Projeto prático de **Entrada de dados, DOM e estruturas condicionais**.

## Conteúdo
- **Laboratório 1:** Verificador de idade com validação de campo vazio, número inteiro e faixa de 0 a 120.
- **Laboratório 2:** Calculadora de média de três notas, validação de notas de 0 a 10 e resultado (média >= 6: aprovado; abaixo: recuperação).
- **Exercícios A–F:** par ou ímpar; desconto de 10% para compras a partir de R$ 200; controle de acesso por idade e cadastro ativo; saudação; classificação de temperatura; validação de nota.

## Executar
Abra `index.html` no navegador. A partir do menu, selecione o laboratório ou os exercícios. Não é necessário instalar dependências.
