# Aula 01 — JavaScript | CEUB

Atividades do material **Desenvolvimento de Interface — Módulo JavaScript, Aula 1**.

## Estrutura
- `laboratorio1`: cadastro simples, variáveis e cálculo de idade estimada (Console).
- `laboratorio2`: calculadora de soma, subtração, multiplicação e divisão, com validação.
- `laboratorio3`: calculadora de média de três notas, com validação de campos e intervalo (0 a 10).
- `exercicios`: seis exercícios de fixação executados no Console.

## Como executar
1. Descompacte o projeto e abra a pasta no VS Code.
2. Para cada laboratório, abra o respectivo `index.html` no navegador.
3. No Laboratório 1 e nos Exercícios, pressione `F12` e abra a aba **Console**.
4. No Laboratório 2 e no Laboratório 3, use os campos e botões da página.
