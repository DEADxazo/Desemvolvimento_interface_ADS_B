# JavaScript na prática — Aula 01

Projeto de laboratório da disciplina **Desenvolvimento de Interface (ADS — CEUB)**, com foco em introdução ao JavaScript, variáveis, tipos de dados e operadores.

## O que foi desenvolvido

- **Laboratório 1 — Cadastro:** exibição de dados, variáveis e estimativa de ano de nascimento.
- **Laboratório 2 — Calculadora:** soma, subtração, multiplicação e divisão, com validação de campos e proteção contra divisão por zero.
- **Laboratório 3 — Calculadora de média:** cálculo de média de três notas, rejeitando campos vazios e notas fora do intervalo 0–10.
- **Exercícios de fixação:** cadastro acadêmico, compra, desconto, comparação de idade, operadores lógicos e par/ímpar (resultados no Console).
- **Quiz:** autoavaliação interativa com oito perguntas.

## Como executar

1. Baixe ou clone este repositório.
2. Abra `index.html` no navegador (ou use Live Server no VS Code).
3. Experimente os laboratórios e o quiz.
4. Para visualizar os exercícios de fixação, clique no botão **Executar exercícios** e abra o Console (F12).
